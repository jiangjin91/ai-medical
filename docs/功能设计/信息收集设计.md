# 信息收集设计

<!-- 本文作用：定义患者咨询前的信息收集方式，强调非诊断式采集和人工分流辅助。 -->

## 当前 MD 的作用

本文件用于设计“问什么、怎么问、问完做什么”。信息收集只用于服务分流、就医准备和人工上下文补全，不用于自动诊断。

## 适用场景

1. 患者不知道该去哪类服务入口。
2. 患者描述流程性问题但缺少关键信息。
3. 转人工前需要整理问题摘要。
4. 检查、报告、缴费等状态查询需要补充身份或业务标识。

## 采集原则

1. 只问完成当前任务所需的最少信息。
2. 优先使用选项、日期、卡片选择，减少长文本输入。
3. 不诱导患者给出完整病历或隐私细节。
4. 触发高风险表达时立即停止普通采集，进入风险处理流程。

## 输出结果

信息收集完成后，应生成结构化上下文：

```text
服务意图：检查报告查询
患者身份：已验证
关键对象：血常规报告
当前状态：报告未出
下一步：展示预计时间或转人工
风险等级：低
```
