# 患者首页设计

<!-- 本文作用：定义患者端首页的信息架构、任务入口和核心体验目标。 -->

## 当前 MD 的作用

本文件用于指导患者端第一屏设计。首页应该让患者立刻看到待办和下一步，而不是先让患者自己猜该点哪个功能。

## 核心目标

1. 进入页面后优先展示“当前待办”。
2. 让患者能从卡片直接进入预约、缴费、检查准备、报告查询、复诊入口。
3. 保留对话入口，但不要让所有事情都必须通过输入问题完成。
4. 对老人、代办人、低健康素养用户保持清晰可读。

## 首页模块

| 模块 | 作用 |
| --- | --- |
| 今日待办 | 展示就诊、检查、缴费、取药、报告等最紧急事项 |
| 服务卡片 | 提供高频服务入口 |
| 智能助手 | 支持自然语言提问和流程引导 |
| 人工帮助 | 明确展示可转接对象和服务时间 |
| 通知提醒 | 展示医院通知、报告更新、预约变更 |

## 体验要求

1. 每张任务卡必须有状态、下一步、操作按钮。
2. 重要提醒使用清楚文案，不依赖颜色表达含义。
3. 失败状态要提供重试和人工入口。
4. 不在首页展示未经授权的敏感医疗信息。
