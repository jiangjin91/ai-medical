# 错误码参考

<!-- 本文作用：统一维护患者端医疗服务助手的错误码、患者提示和内部处理建议。 -->

## 当前 MD 的作用

本文件用于前端、AI 服务、业务服务和人工客服对齐错误语义。新增错误码时，应同时补充患者端文案和内部处理方式。

## 错误码列表

| 错误码 | 场景 | 患者端提示 | 内部处理 |
| --- | --- | --- | --- |
| `AUTH_401` | 未登录或登录过期 | 请先完成登录后再查询就诊信息。 | 引导重新认证 |
| `AUTH_403` | 无权查看当前信息 | 当前账号暂无权限查看该信息，请确认是否为本人或已获得授权。 | 检查授权关系 |
| `MED_001` | 医疗安全边界命中 | 你的情况可能需要人工或线下医疗帮助，请优先联系医院或急诊服务。 | 进入风险处理流程 |
| `BIZ_404` | 未找到业务数据 | 暂未查询到相关记录，请核对时间、院区或就诊人信息。 | 记录查询条件摘要 |
| `BIZ_503` | 医院业务系统不可用 | 当前医院系统暂时无法返回结果，请稍后重试或转人工处理。 | 降级并创建转接入口 |
| `SYS_500` | 系统未知异常 | 系统暂时开小差了，请稍后重试。 | 记录 `traceId` 排障 |
