# 日志规范

<!-- 本文作用：定义日志记录、敏感信息脱敏、审计事件和排障信息的基本要求。 -->

## 当前 MD 的作用

本文件用于约束医疗场景下的日志行为。患者隐私优先，日志要能排障，但不能成为敏感数据的二次泄露源。

## 日志原则

1. 脱敏记录身份证号、手机号、就诊卡号、完整病历、完整报告内容。
2. 脱敏在日志中输出 `.env`、token、密钥、证书。
3. 对话原文默认不入普通日志；确需留存时必须脱敏、授权并标明用途。
4. 外部接口错误记录追踪编号、接口名称、耗时、错误分类，不记录敏感入参。
5. 高风险拦截、人工转接、关键操作确认必须留审计事件。

## 建议字段

| 字段 | 说明 |
| --- | --- |
| `traceId` | 一次请求或会话的追踪编号 |
| `sessionId` | 脱敏后的会话标识 |
| `intent` | 识别出的业务意图 |
| `riskLevel` | 风险等级 |
| `action` | 执行动作 |
| `result` | 成功、失败、降级或转人工 |
| `durationMs` | 接口耗时 |
