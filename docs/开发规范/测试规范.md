# 测试规范

<!-- 本文作用：定义患者端医疗服务助手的测试范围、重点场景和验收方式。 -->

## 当前 MD 的作用

本文件用于指导新增功能如何验证，尤其关注医疗安全边界、任务流程闭环、接口异常和患者端体验。

## 测试重点

1. 高风险表达必须命中确定性拦截。
2. 未登录、未授权、授权过期时不能泄露患者信息。
3. 检查检验流程要覆盖预约、准备、到检、报告状态、复诊建议入口。
4. 人工转接必须保留脱敏摘要和失败原因。
5. 电商遗留术语不能出现在患者端核心文案。

## 前端验证

1. 运行 `npm run build` 确认构建通过。
2. 核心页面需要覆盖桌面和移动端布局。
3. 任务卡、对话抽屉、人工转接状态必须有加载、空状态、失败状态。

## 后端验证

1. AI 服务需要覆盖意图识别、流程编排、风险拦截。
2. 业务服务需要覆盖正常返回、空数据、超时、权限不足。
3. 与外部医院系统联调前，必须先用模拟数据完成契约测试。
