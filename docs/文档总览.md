## 当前 MD 的作用

本文件是项目文档入口，帮助团队快速判断“要查什么内容应该看哪个文档”。后续新增需求、架构、流程、接口、规范时，应优先放入对应目录，避免散落在聊天记录或代码注释里。

## 文档维护规则

1. 每个 Markdown 文档顶部必须有 `last_updated`、`status`、`owner`。
2. 每个 Markdown 文档正文开头必须写明“当前 MD 的作用”。
3. 涉及医疗建议、诊断、处方、用药剂量、治疗方案的内容必须标明“不在系统自动回答范围内”。
4. 需求变化先更新 `患者端医疗服务智能客服需求文档.md`，再同步架构、设计和接口文档。
5. 已实现能力要能从代码追溯到设计文档，未实现能力必须保持 `draft` 或 `planned` 状态。
