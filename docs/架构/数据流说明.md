# 数据流说明

<!-- 本文作用：说明患者一次咨询从进入页面到自动处理、转人工、结果回写的主要数据流。 -->

## 当前 MD 的作用

本文件用于帮助开发和测试理解数据如何穿过前端、AI 服务、业务接口和人工系统。后续接口联调、日志审计、隐私评审都应参考这里。

## 主流程

```text
患者发起咨询
  -> 前端采集输入与会话上下文
  -> AI 服务识别意图和风险
  -> 任务规划器选择流程
  -> 业务适配层查询预约/检查/报告/缴费状态
  -> AI 服务生成任务卡或回复
  -> 前端展示下一步动作
  -> 必要时转人工并携带脱敏摘要
```

## 数据分类

| 数据类型 | 示例 | 处理要求 |
| --- | --- | --- |
| 会话数据 | 患者问题、上下文、任务状态 | 最小化保存，避免记录敏感原文 |
| 身份数据 | 手机号、证件号、就诊卡号 | 只用于鉴权，不进入普通日志 |
| 就医数据 | 预约、检查、报告、缴费状态 | 必须校验身份与授权 |
| 知识数据 | 科室说明、检查准备、院内导航 | 必须来自医院审核版本 |
| 转接数据 | 问题摘要、已查状态、失败原因 | 传递给人工前应脱敏 |

## 审计点

1. 患者身份校验结果。
2. 意图识别结果。
3. 高风险拦截命中原因。
4. 外部业务接口调用结果。
5. 关键操作的二次确认记录。
6. 人工转接的分流队列和处理状态。
